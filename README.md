# BookNook – A Small Online Library

**BookNook** is a modern online library management platform designed to make discovering, sharing, and borrowing books easier and more convenient. It provides a user-friendly environment where readers can explore a collection of books, discover new arrivals, and borrow their favorite books from anywhere.

Users can create an account, add their own books, manage their book collections, and borrow books for a limited period. They can also track their borrowed books and return them easily through a simple and intuitive interface.

### Key Features

- **User Authentication:** Secure registration and login with Google authentication.
- **Explore Books:** Browse and discover books from different categories.
- **Add Books:** Authenticated users can add new books to the library.
- **Manage Books:** Users can update and delete the books they have added.
- **Borrow Books:** Borrow available books through a simple process.
- **My Borrowings:** View and manage borrowed books.
- **Responsive Design:** Enjoy a smooth browsing experience across desktop, tablet, and mobile devices.
- **Modern UI:** Clean design with an intuitive navigation system.
